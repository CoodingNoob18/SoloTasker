# SoloTasker
_Welcome to SoloTasker, built by NO-LIFE GAMERS. This project is a gamified productivity application combining a task manager with a Pomodoro timer._

_To make productivity fun, the app features a custom economy. Users can assign direct real-life rewards to specific tasks, or earn virtual coins from focus sessions to "buy" custom rewards in their personalized store (e.g., watching an anime episode or playing a game). The system currently utilizes a straightforward manual account creation and login process._
